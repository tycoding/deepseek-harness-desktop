# @deepseek-ai/dsh-client-ui-browser

[English](README.md) | 中文

固定式网页浏览插件参考。该包在每个有效会话页头的最右侧增加只显示图标的**打开右侧工具区**操作，并在应用最右侧的工具区域中打开网页浏览器。面板会占用布局宽度而不是覆盖会话，同时关闭互斥的会话详情栏；没有当前会话时，入口和面板都会消失。入口使用通用面板图标，表示共享工具区域，而不是只表示当前的网页浏览能力。

浏览器通过一份瞬时共享状态保持多个页签。每个页签可以是空白页、规范化后的 `http:` 或 `https:` 地址，或通过文件选择器打开的本地 `.html`／`.htm` 文件。在应用内点击 HTTP(S) 链接会将其作为浏览器页签打开。在打包后的桌面应用中，打开生成的 HTML 文件会通过隔离的桌面连接读取文件并在面板中打开；其他文件类型仍按操作系统的默认方式打开。切换页签只隐藏上一页面，不会重新加载；刷新操作只更新当前页签。关闭最后一个页签时会立即补回一个空白页签。

没有协议的网址会自动补全 `https://`。其他协议和应用自身地址会被拒绝。远程网页和本地 HTML 都运行在隔离的 iframe 中，允许脚本、表单和页面弹窗，但不允许同源访问；页面内容不会获得 Node.js 或 Electron 能力。**在系统浏览器中打开**只对远程网页可用，并遵循桌面端现有的外部跳转规则。

本地 HTML 使用仅在当前界面进程中有效的临时地址。桌面连接只接受绝对 `.html` 和 `.htm` 路径，将文件限制在 10 MB 以内，并且只返回文本，不会向应用页面暴露 Electron 或 Node.js。替换或关闭本地页签时会释放对应地址，插件卸载时会释放所有剩余地址。由于这些地址在界面重启后失效，页签状态不会持久保存。

客户端插件通过 slot 注册表等待会话级的 `conversation.session.header.utilities` 和 `shell.utility-panel` 两个位置出现，再用同一个状态句柄各注册一个条目。客户端服务把链接和生成的 HTML 文件请求送入这份状态，因此入口、面板与会话文件打开操作可以按会话共享打开状态、页签顺序、当前选中项与页面地址，无需引用属主组件。

## 模型体验

无。浏览器只是本地查看界面；这里没有任何内容进入模型请求。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **部分网站禁止被 iframe 嵌入**：发送 `X-Frame-Options` 或严格 `frame-ancestors` 策略的网站可能显示空白页或拒绝页面，此时请使用**在系统浏览器中打开**。
- **本地 HTML 主要面向单文件**：临时地址无法解析相对路径引用的图片、样式、脚本和相邻页面；内容自包含的 HTML 可以正常运行。
- **跨域页面内跳转对外部不可见**：地址栏记录提交给页签的网址，但无法跟随页面内部点击产生的跨域地址变化，因此目前不提供浏览历史按钮。
- **页签是瞬时状态**：重启或重新加载应用会清空所有打开的页面。
